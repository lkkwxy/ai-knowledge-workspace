# 个人知识库使用手册

这是一份示例文档，用来做 chunking 实验。它故意混了长段、短段、列表和多个小节，方便看出三种切法的差异。

## 什么是知识库

知识库是一个把你长期积累的资料集中存放、并能用自然语言提问的系统。它和普通的文件夹不同：文件夹靠你记得文件名和路径，知识库靠语义检索——你描述你想找的东西，它帮你找出最相关的片段。对写作者和研究者来说，最大的价值是「把过去的自己沉淀的东西重新调出来用」，而不是让资料躺在硬盘里吃灰。

## 支持的文件类型

当前版本支持三类文件：纯文本（.txt）、Markdown（.md）、PDF（.pdf）。纯文本和 Markdown 直接读取即可，PDF 需要先做文本抽取。Word 和网页暂不支持，计划在后续版本加入。导入时单个文件大小上限为 20 MB，超过需要先拆分。

## 资料是怎么被检索到的

导入一份文档后，系统会把它切成若干小块，每一块单独编码成一个向量并存起来。你提问时，问题也被编码成向量，系统计算问题和每一块的相似度，取最相关的几块作为答案的依据。这个过程的质量高度依赖「切块」这一步：块切得太大，一块里混了多个主题，检索会不精确；块切得太小，单块信息不足，又容易丢失上下文。因此同一份文档，用不同的切法导入，问同一个问题，得到的答案质量可能差别很大。

## 引用与拒答

每一条回答都会标注它依据了哪些片段，你可以点开看原文，确认系统没有编造。如果检索到的片段相似度都很低，系统会判定「没有找到相关资料」并直接拒答，而不是用模型自己的知识硬凑一个答案。这是知识库和通用聊天机器人最重要的区别：它只对你的资料负责。

## 隐私

所有资料默认只存在你本地。embedding 用本地模型计算，不上传任何第三方。只有在你主动提问、需要生成最终答案时，才会把检索到的片段发给大模型。如果你连这一步也不想联网，可以在设置里切换成本地大模型。

## 常见问题

- 导入后多久能检索？通常几秒内，取决于文档长度。
- 删除文档会连带删除它的向量吗？会，删除是彻底的。
- 能跨多份文档提问吗？能，检索默认在你全部资料范围内进行。
